ORE v3 deploy

EdgeORE builds the ORE v3 Deploy instruction for the public ORE program by Regolith Labs and shows the live 5×5 board.

Steps

  1. Choose Mainnet (or Devnet to practise) in the network selector.
  2. In the ORE card, select one or more blocks and set the amount. On mainnet the amount is clamped to 0.01 SOL per deploy; Rounds is fixed at 1 and nothing spends automatically.
  3. On mainnet, tick the risk confirmation ("real SOL, may be lost"). Review stays disabled until you do.
  4. Tap Review deployment and read the exact message.
  5. Sign in your wallet. EdgeORE checks that the signed bytes match the reviewed message.
  6. EdgeORE submits it once. If the round has moved on (rounds last about a minute), you get a fresh review; a signed transaction is never resent.

Costs

A first deploy also pays rent for your miner account, so it costs more than the deploy amount (about 0.0145 SOL was observed in mainnet-fork simulation for a 0.01 SOL deploy). Network fees are not refundable.

EdgeORE does not promise or estimate any ORE outcome.
