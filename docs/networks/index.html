Networks and the network selector

EdgeORE has one network selector at the top of Home. It drives the wallet connection, balance reads and the ORE card together.

Network Badge Funds RPC
Devnet Devnet · Test SOL only Test SOL https://api.devnet.solana.com
Testnet Testnet Test SOL https://api.testnet.solana.com
Mainnet-beta Mainnet · Real SOL · capped 0.01 Real SOL https://api.mainnet-beta.solana.com

Changing network means your wallet authorizes for that network. Requests go directly from your phone to these public RPC endpoints, which are run by third parties.
