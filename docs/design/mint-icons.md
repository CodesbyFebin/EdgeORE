# Mint interface icon map

All ordinary icons are 24×24 local outline vectors in `ui/components/Icons.kt`, with rounded 2 px strokes. Supporting icons use 18–20 dp; icon buttons retain 48 dp touch targets. Decorative icons have null descriptions; standalone buttons name their action. Status text always accompanies colour.

SOL/ORE/SKR cards currently use neutral Wallet/Coins outlines. They are not official token logos. No official brand assets were present in the inspected app resources; counterfeit logos or unchecked downloaded artwork are not substituted. The native three-stroke EdgeORE mark and existing owner-supplied rock/pickaxe are the brand/illustration exceptions. ORE's existing circle/strike motif labels the read-only board; it is not evidence of a connected token or mining capability.
