Documentation

How to install and use EdgeORE. Technical sources are in the repository docs.

Getting started

Install the EdgeORE APK and connect your Solana wallet with Mobile Wallet Adapter.

Networks and the network selector

EdgeORE uses one network selector for the wallet, balances and the ORE card: Devnet, Testnet or Mainnet-beta.

ORE v3 deploy

How EdgeORE builds an ORE v3 Deploy: 0.01 SOL mainnet cap, risk confirmation, exact-message review, wallet signature and a single submit.

Signed receipts

EdgeORE stores a receipt for each action, signed with an Android Keystore key; the receipt checker verifies the integrity of signed receipt contents.

AI

EdgeORE's AI options: an AI host you own, or an allowlisted on-device model downloaded after consent. No model is bundled in the APK.

ZK Proof

EdgeORE's ZK Proof screen: no prover is configured in this build.

Theme

Choose Dark, Light or System theme in EdgeORE Settings; the choice is saved on your phone.

Troubleshooting

Fixes for common EdgeORE problems: install conflicts, wallet connection, Not read balances, refused reviews and stale ORE rounds.

Security

EdgeORE's security model and how to report a vulnerability privately.
