# Protocol and model provenance

- Solana cluster in the app: devnet.
- Supported transaction: System Program transfer. Mobile Wallet Adapter client 2.0.3. The app does not hold a seed.
- ORE program, SKR, VPN, cloud sync, and bandwidth earning are not pinned and not enabled.
- AI client speaks an Ollama-compatible local API. No model name, digest, or license is pinned. No weights are in the APK.
- Cancellation that only closes the client is "Stopped receiving."
- Node protocol tests exist. The live agent test is skipped when the agent is absent.
- A private IP is not proof of ownership.
