Getting started

Install

  1. Download the APK from GitHub Releases. Release builds are signed with the certificate whose SHA-256 is c2279fb0357bd3b78e577d57b93d5d9af273fb03191264811b6e3696165e62d2 (see Release verification).
  2. Allow installs from your browser or file manager, then install com.edgeore.app.
  3. If Android shows INSTALL_FAILED_UPDATE_INCOMPATIBLE, an earlier EdgeORE signed with a different certificate is installed. Android will not upgrade across certificates; uninstalling removes EdgeORE's on-device data (including the vault), so export anything you need first.

Connect your wallet

  1. Pick a network in the network selector at the top (start with Devnet).
  2. Tap Connect. EdgeORE asks your Mobile Wallet Adapter wallet to authorize for the network you picked.
  3. Approve in your wallet. EdgeORE receives only your public address. Balances that have not been read show Not read.
