# Code of conduct

EdgeORE welcomes people with different backgrounds, experience levels and accessibility needs. This code applies to repository issues, pull requests, discussions and other project spaces managed by its maintainers.

## Participation

- Treat people with respect. Critique ideas and code without attacking the person.
- Use clear, constructive language; explain problems and help others understand your reasoning.
- Respect privacy, consent and accessibility needs. Do not publish someone else's personal information, credentials or private messages.
- Keep technical claims accurate. Distinguish proposals, source implementation, test results and observed device behavior.
- Accept feedback and corrections, and give others room to participate.

Harassment, discriminatory language, threats, sexual harassment, impersonation, deliberate intimidation, doxxing and repeated disruptive behavior are unacceptable. Disagreement about implementation or project direction is welcome when expressed respectfully.

## Reporting

Contact the repository maintainer, [CodesbyFebin](https://github.com/CodesbyFebin), through an available private contact method. If none is available, open a minimal issue asking for a private conduct-reporting channel; leave incident details and identifying information out of that public issue. Security vulnerabilities follow [SECURITY.md](SECURITY.md).

## Moderation

Maintainers may ask for changes, remove disruptive content or restrict participation using GitHub's moderation tools. Responses should consider the impact, context and whether the behavior is repeated. Reports and personal details should be shared only as needed to handle the incident. People raising a concern in good faith must not be targeted for doing so.
