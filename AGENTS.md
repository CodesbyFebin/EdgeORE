# EdgeORE contributor-agent contract

Read the handoff, current evidence ledger, FORK-GUIDE.md and relevant extension docs before editing.
Preserve exact reviewed wallet bytes, signature verification, durable writes before network side
 effects and observation-only recovery. Unknown outcomes never permit automatic resend.

Offline kit planning is advisory; it grants neither execution nor wallet approval. The artifact
manifest verifier checks file integrity against an unsigned manifest, not provenance or payout.
Default remote storage remains disabled until explicit provider configuration and qualification.
Keep device-bound backup distinct from portable restore.

Use focused branches. Record command, environment, exit, tested source and artifact hashes. Report
Android, screenshots, receipt checker, backend and settlement suites separately. Existing evidence
is historical; do not turn NOT_RUN into PASS through a source review or roadmap.

Do not copy upstream code without inspecting its license and preserving attribution. Do not choose
an owner license, deployment, release publication or financial action without authorization. Do not
commit credentials. Keep independent architecture implementations separate from vendor imports.

For this extension kit, run the offline policy, kit and gateway suites; run Android qualification
on a build host before merge. No access to a device or private service may be assumed.
