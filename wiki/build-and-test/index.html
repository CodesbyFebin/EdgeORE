Build & test

Requirements: JDK 17, Android SDK (compile SDK per app/build.gradle.kts). Dependency versions are pinned (Kotlin 2.0.21, AGP 8.7.3, MWA clientlib-ktx 2.0.3); do not bump them without re-testing.

./gradlew :app:assembleDebug ./gradlew :app:testDebugUnitTest ./gradlew :app:lintDebug

Each suite is recorded on its own; counts are never added together.

Suite Commit Ran Passed Skipped Failed
Android unit tests (:app:testDebugUnitTest) main 4f6e207 391 382 9 0
Android unit tests (:app:testDebugUnitTest) PR #30 head 396 387 9 0

Other suites (receipt checker, edgeore-kit Python tests, screenshot verification, release R8 build) run in GitHub Actions; see each workflow run for its own counts. Lint passes against committed baselines (config/detekt, config/ktlint).
