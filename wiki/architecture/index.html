Architecture

Part Path Role
Android app app/ Kotlin/Compose UI, wallet coordinator (MWA), ORE v3 instruction builder, operation ledger, Keystore-signed receipts
On-device LLM bridge ondevice-llm/ Java-only module wrapping LiteRT-LM 0.8.0 so it never reaches the app's Kotlin compile classpath
Receipt checker tools/receipt-checker/ Standalone JVM tool; verifies the integrity of signed receipt contents
ORE fork simulation tools/ore-fork-sim/, tools/ore-fixtures/ Mainnet-fork simulation and fixtures for the ORE Deploy instruction
Offline kit tools/edgeore-kit/ Python tooling and tests
Storage gateway services/storage-gateway/ Optional self-hosted gateway you run yourself

Trust spine: exact-message review → MWA sign → returned-bytes check → one separate submit → Keystore-signed receipt. An unknown outcome is re-read from chain after restart and never resent.

The ORE v3 Deploy instruction (ix 6, 12 accounts) was checked against regolith-labs/ore at commit 48c203bd.
